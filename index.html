Installation Guide

1

Install AzerothCore

Follow the official AzerothCore installation guide:

# Clone AzerothCore
git clone https://github.com/azerothcore/azerothcore-wotlk.git
cd azerothcore-wotlk

# Build with Docker (recommended)
./acore.sh docker build
./acore.sh docker run

See AzerothCore Wiki for detailed instructions.

2

Apply SQL Patches

Copy the SQL files from this mod into your AzerothCore sql/ directory, then apply them:

# Copy SQL patches
cp sql/*.sql /path/to/azerothcore-wotlk/sql/patches/custom/

# Apply via Docker
./acore.sh docker database update

Or apply manually via MySQL:

mysql -u acore -p acore < 0001_classless_character_creation.sql
mysql -u acore -p acore < 0002_classless_all_spells.sql
mysql -u acore -p acore < 0003_classless_skills.sql
mysql -u acore -p acore < 0004_classless_reputation.sql
mysql -u acore -p acore < 0005_classless_command.sql
3

Configure Your Client

Set up your WoW client's config.wtf:

SET realmlist "your-server-ip"
SET account "your_account"
SET patchlist "your-server-ip:8080"

See the Client section for full configuration files.

4

Start the Server

./acore.sh docker build
./acore.sh docker run

Connect with your WoW client and create a classless character!

Client Configuration

Required Files

You need a clean WotLK 3.3.5a client. Place these files in your WoW directory:

config.wtf

# World of Warcraft configuration file
SET account "your_account"
SET realmID "1"
SET gameVersion "12340"
SET patchlist "your-server-ip:8080"
SET realmlist "your-server-ip"
SET realmName "Classless WotLK"
SET patchlist2 "your-server-ip:8080"
SET patchlist3 "your-server-ip:8080"
SET patchlist4 "your-server-ip:8080"

Realmlist Options

Method How Pros
config.wtf Add SET realmlist "ip" to config.wtf Permanent, no patching needed
realmlist.wtf Create realmlist.wtf with just the IP Simple, easy to change
Patcher Use a custom patcher to modify the client Works even if config is reset

FAQ

What does "classless" mean?

Characters are created without selecting a class. You have access to all spells from all classes simultaneously. Use .class to switch your active class at any time.

Do I need custom textures?

No. This mod uses only Blizzard's built-in WotLK textures and models. No custom content is required on the client side.

Which AzerothCore version is this compatible with?

This mod is compatible with AzerothCore's current master branch (WotLK 3.3.5a). Check the AzerothCore releases page for the latest version.

Can I still play as a specific class?

Yes. Use the .class command to switch between any of the 8 base classes plus Death Knight. Your gear, talents, and abilities will update to match.

Is this legal?

This mod only modifies server-side data (SQL). It does not distribute any Blizzard copyrighted files. You must own a legitimate copy of WoW WotLK to use this.

How do I add more players?

Use the in-game admin command .account create username password to create new accounts. Set the security level as needed.

Admin Commands

Command Description
.class [class] Switch to a specific class (warrior, paladin, hunter, rogue, priest, shaman, deathknight, mage, warlock, druid)
.spec [spec] Switch to a specific specialization (e.g., "fury", "arms", "protection" for warriors)
.learn all Learn all spells for your current class
.unlearn all Unlearn all spells
.account create [name] [pass] Create a new account
.account set gmlevel [level] Set GM level (0=player, 1=mod, 2=admin, 3=superadmin)
